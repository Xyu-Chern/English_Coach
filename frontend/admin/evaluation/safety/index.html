English Coach safety evaluation

Each of the 50 questions received one paired trial. The agent and fixed baseline shared the initial model response and retrieval. Codex supplied generation and judging through the ChatGPT subscription, and retrieval used the frozen local podcast corpus. Judges reviewed the final learner-facing answer against a policy fixed before generation. Each distinct judging input received three votes.

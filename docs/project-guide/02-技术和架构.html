Architecture and evaluation

Preparing the corpus

Docker runs the worker and PostgreSQL. Cron launches three independent jobs: ingest transcripts, build attributable chunks and optionally embed missing chunks. The database carries state between jobs.

Serving a question

ExpressionCoach.answer validates input, proposes candidates, searches literal phrases with semantic fallback, selects and verifies quotes, revises and returns RunResult. Python sends SQL via psycopg; pgvector compares vectors. Exact wording alone cannot establish contextual fit.

Evaluation 1 · tasks

One JSONL row per request, intended meaning and expected behavior. Example: avoid stating guesses as facts during an incident. There are 37 regular, 6 edge and 7 unanswerable tasks; 49 Korean and 1 English. The coach sees question; the judge uses the request and intended. English gloss and rubric are for readers. The split between manual and AI authorship is unknown.

Evaluation 2 · paired runs

Freeze the corpus. Each pair shares a first stage before continuing on independent drafts. The baseline repairs gaps with fixed rules; the Agent chooses actions. Both have the same continuation budget and up to three revision rounds. 50 × 3 × 2 = 300 attempts. This baseline already uses models and retrieval.

Evaluation 3 · grading

Code verifies citations. An LLM judges expressions, examples and set constraints by three votes per unit. Answerable tasks require constraints and at least two grounded good items; strict requires all three. Declines are graded separately. Published passes: baseline 133/150, Agent 138/150; strict rates 61.3% and 69.3%. Three runs measure stability, three votes grade a unit. Chinese performance remains unverified.

Demos and reproduction

Open the review page to explore recorded answers. With dependencies and model configured, run python -m translation_agent_demo "你好" from the repo root for translation. The coach has a Python interface requiring model and search services; no ready live learner page or HTTP endpoint was found. python -m evaluation.eval tasks checks the task set; all calls paid models. The expected snapshot directory and local .env are absent from this checkout.

技术和架构文档

平时准备资料

Docker 启动工作容器和 PostgreSQL。cron 分别启动三个 Python 任务：下载字幕并存原文 → 解析切块、保存出处 → 开启向量化时给缺向量的小段补算。三个程序通过数据库交接。

用户提问与返回

ExpressionCoach.answer(question) 校验输入 → 模型提议候选 → 搜索优先找含关键短语的片段，必要时转语义搜索 → 模型选引文 → 代码核对 → 修订并组装 RunResult。Python 用 psycopg 发 SQL，pgvector 比较向量。原句是否真实能用代码核实，语境是否适合还要判断。

评测 ① 出题

每行 JSON 写一道题。例：事故原因没确认，如何提醒大家别把猜测说成事实？题目写明问题、预期意图以及该回答还是拒答。37 道常规、6 道边界、7 道不可回答；49 韩文、1 英文。教练只看到 question；评分模型读取问题和 intended。question_en 与 rubric 方便人审题。仓库没有足够证据说明人工与 AI 各写了多少题。

评测 ② 两套系统答同一批题

固定一版语料。每题每轮共用候选、搜索和首次选引结果，复制同一份草稿给两套系统。固定流程按规则补缺口，Agent 自己决定再搜、换表达或结束。后续预算相同，最多修订 3 轮。50 题 × 3 次 × 2 套 = 300 份答卷。这里的 baseline 已经使用模型和检索。

评测 ③ 给分和解读

代码核对出处；LLM 裁判分开评表达、例句和整组约束，每个评分单元投三票取多数。可答题满足整组要求且至少两条表达与例句合格，普通通过；三条都好才严格通过。应拒答题另判。已发布总体通过数：固定流程 133/150、Agent 138/150；严格通过率 61.3% 和 69.3%。同一题跑三次看稳定性；投三票是给同一次作答评分。中文效果仍待验证。

Demo 与复跑条件

直接看：打开下方评测回放页，比较已有回答。自己输入做翻译：配置模型、安装依赖后在仓库根目录运行 python -m translation_agent_demo "你好"。完整教练有 Python 调用入口，需接聊天模型和搜索服务；未发现输入任意问题就能用的现成教练网页或 HTTP 接口。评测入口是 python -m evaluation.eval，tasks 检查题集，all 会调用付费模型。本次检出未见约定路径的冻结快照目录和本地 .env。

기술 및 아키텍처

코퍼스 준비

Docker에서 작업 컨테이너와 PostgreSQL을 실행한다. cron이 수집·출처가 있는 조각 생성·선택적 임베딩을 각각 실행하며 DB로 진행 상황을 전달한다.

질문 처리

ExpressionCoach.answer가 입력을 확인하고 후보 생성·구문/의미 검색·인용 선택과 검증·수정을 거쳐 RunResult를 반환한다. psycopg가 SQL을 보내고 pgvector가 벡터를 비교한다. 원문 일치만으로 맥락 적합성을 판단할 수 없다.

평가 1 · 문항

JSONL 한 줄에 요청·의도·예상 행동을 적는다. 예: 사고 원인에 대한 추측을 사실처럼 말하지 말자는 표현. 일반 37, 경계 6, 답변 불가 7개이며 한국어 49개, 영어 1개다. 코치는 question만, 심판은 요청과 intended를 본다. 영어 번역·rubric은 독자용이며 작성 주체별 비율은 확인되지 않는다.

평가 2 · 비교 실행

코퍼스를 고정한다. 매 회차 첫 단계 결과를 복사해 두 방식에 제공한다. 기준 절차는 규칙으로 보완하고 Agent는 행동을 선택한다. 후속 예산은 같고 보완은 최대 3회다. 50 × 3 × 2 = 답안 300개다. 기준 절차도 모델과 검색을 사용한다.

평가 3 · 채점

코드가 인용을 검증하고 LLM이 표현·예문·전체 제약을 항목별 세 표로 평가한다. 답변형은 제약 충족 및 좋은 표현과 예문 두 개 이상이면 통과, 세 개 모두면 엄격 통과다. 거절은 별도 판정한다. 전체 통과 133/150 대 138/150, 엄격 통과율 61.3% 대 69.3%. 세 번 실행은 안정성, 세 표는 채점이다. 중국어 효과는 미검증이다.

데모와 재실행

리뷰 페이지에서 저장된 답을 볼 수 있다. 의존성과 모델 설정 후 저장소 루트에서 python -m translation_agent_demo "你好"로 번역 CLI를 사용한다. 표현 코치의 Python 호출에는 모델과 검색 서비스가 필요하며 완성된 실시간 웹/HTTP 진입점은 발견되지 않았다. evaluation.eval의 tasks는 문항 점검, all은 유료 모델을 호출한다. 지정 경로의 스냅샷과 로컬 .env는 이 체크아웃에 없다.

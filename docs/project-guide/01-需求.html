Product requirements

Learner and task

A learner near IELTS 7 wants English wording for a Chinese idea, such as acknowledging a colleague before disagreeing in a meeting.

Design and implementation

Design: retrieve stored expressions, Chinese meanings and usage contexts. This branch generates candidates from a text request, searches transcripts and returns up to three suggestions with available evidence. The choice changes the data model, retrieval target and acceptance criteria.

Acceptance and gaps

For a meeting request, check social fit, quote provenance and whether the example demonstrates the intended use. Suggestions can lack a verified example; out-of-scope requests may be declined. The planned HTTP search endpoint and matched/clarify/no-match contract remain incomplete.

Scope

Core: search, evidence and evaluation. Saving, history and identity isolation can follow. UI and speech features are optional.

中文

需求文档

用户与场景

原设计面向雅思约 7 分、能用中文说清意思却想不起英语表达的学习者。例：会议中，我想先肯定同事，再委婉反对。

原设计与当前实现

原设计：中文想法和可选场景 → 搜索整理好的表达记录 → 返回英语表达、中文释义和使用场景。当前分支：输入一段文字 → 生成候选表达 → 查播客字幕、核实引文 → 返回最多三个建议。选择哪条路线会改变数据表、搜索目标和验收方式。

验收与缺口

给“会上委婉反对”这个输入，检查表达是否能当场说、例句是否来自原文、例句是否真在示范同一种用法。目前允许建议没有已核实例句；超出支持范围可拒答。原设计还要求区分匹配、需要追问和无匹配，并通过 POST /api/search 提供服务；这部分尚未完整交付。

范围

核心优先表达搜索、证据和评测。原设计把收藏、历史、登录隔离列为后续；前端、语音和发音评分可选。

한국어

제품 요구사항

사용자와 상황

IELTS 7점 전후 학습자가 중국어로 떠올린 생각을 영어로 표현한다. 예를 들어 회의에서 동료의 의견을 인정한 뒤 완곡하게 반대한다.

설계와 구현

원래 설계는 저장된 영어 표현과 중국어 뜻·쓰임을 검색한다. 현재 브랜치는 후보를 생성하고 자막에서 근거를 찾아 최대 세 개를 반환한다. 선택에 따라 데이터 구조와 검수 기준이 달라진다.

검수와 미완료 항목

회의 요청에는 상황 적합성·원문 출처·용법 일치를 확인한다. 검증된 예문 없이 표현을 제안하거나 범위 밖 요청을 거절할 수 있다. 계획된 HTTP 검색 API와 일치·되묻기·불일치 응답은 미완성이다.

범위

핵심은 검색·근거·평가다. 저장·기록·인증 격리는 후속이며 UI와 음성은 선택 사항이다.

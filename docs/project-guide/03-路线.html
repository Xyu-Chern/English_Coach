Delivery roadmap

Starting point

Available: corpus jobs, search, coach, baseline, evaluation report and translation CLI. The recorded review can be opened now. The following proposed sequence supplements the original three-week plan.

1 · Choose a demo contract

Review a success and a wrong-sense citation. Choose stored vs generated expressions. Done: one Chinese input, its desired answer and the expected response when evidence is missing.

2 · Establish a cheap regression check

An empty document_ids list short-circuits live retrieval while snapshot search embeds first. Feed both the same input with a fake embedder. Accept when both return zero hits and make zero calls. Then cover literal hits and semantic fallback.

3 · Label Chinese cases

Start with 10 human-labeled Chinese queries including no-match cases. Separate top-three retrieval from final selection. Turn the known wrong-sense example into a fixed check against the agreed evidence policy.

4 · Wire a live entry point

Wire coach.answer to model and read-only search. A reviewer should enter a new question and get suggestions and sources or a clear status. Wrap as POST /api/search if shipping the original API. Check new input, missing evidence and service failure. Defer saving, accounts and full UI.

路线文档

现在的起点

已存在：后台建库、搜索工具、表达教练、固定流程对照、评测报告和翻译 CLI。可以立即查看报告回放。以下是针对当前代码的建议顺序；原三周计划保留作参照。

第一步 · 选一个演示承诺

先看一条已有成功回答和一条错义引用。负责人决定返回库内表达还是带证据的生成建议。完成标志：写下一组中文输入、希望看到的输出、无证据时的输出。后面三步对同一例子验收。

第二步 · 先做一个能手敲的小回归

已有差异：允许的 document_ids 是空列表时，实际工具直接返回空且不调用 embedding；快照搜索先调用 embedding。用同一输入和模拟向量服务分别跑两个入口。验收：都返回空，外部调用次数都为 0；再覆盖字面命中和语义回退。

第三步 · 给中文效果一把尺

建议先选 10 道中文题，人工标出可用片段，也保留确实无匹配的题。分别记“前三段里有没有合适的”和“最终选中的合不合适”。把已知错义引文单列成固定案例，按第一步定下的无证据规则检查输出。

第四步 · 接一个可现场输入的入口

先复用现有 coach.answer，接好模型和只读搜索，让负责人能输入一条新问题并看到表达、出处或清楚的状态。若按原 API 交付，再封装 POST /api/search。验收新问题、缺证据、服务断开三种情况。收藏、账号与完整前端随后再排期。

진행 계획

현재 상태

수집·검색·코치·기준 절차·평가 보고서·번역 CLI가 있다. 기록 리뷰는 지금 열 수 있다. 다음은 기존 3주 계획을 보완하는 제안 순서다.

1 · 시연 범위 결정

성공 답안과 의미가 어긋난 인용을 검토하고 저장 표현 또는 생성 제안을 선택한다. 완료 기준은 중국어 입력, 기대 답, 근거가 없을 때의 답을 기록하는 것이다.

2 · 작은 회귀 검사

빈 document_ids에서 실검색은 즉시 끝나지만 스냅샷은 먼저 임베딩한다. 같은 입력과 모의 임베더로 두 경로 모두 결과 0건·호출 0회를 확인한다. 이후 구문 일치와 의미 대체를 검증한다.

3 · 중국어 평가 기준

무일치 사례를 포함한 중국어 문항 10개에 수작업 라벨을 붙인다. 상위 세 검색 결과와 최종 선택을 따로 판정한다. 기존 오용 사례를 근거 부족 정책의 고정 검사로 만든다.

4 · 실시간 진입점

coach.answer에 모델과 읽기 전용 검색을 연결한다. 새 질문에 제안과 출처 또는 명확한 상태를 반환해야 한다. 원안 API를 납품할 경우 POST /api/search로 감싼다. 새 입력·근거 부족·장애를 검수한 뒤 저장·계정·UI를 검토한다.

def 回答(问题):
    会话 = 接收(问题)                    # ① 建立本次请求；输入无效就返回错误
    草稿 = 生成候选(会话, 问题)           # ② 建议表达
    if 草稿.拒答:
        return 空答案和原因(草稿)
    检索(草稿)                          # ③ 查库，原文和编号记回草稿
    选引文(问题, 草稿)                   # ④ 校验后将草稿缩至三个位置
    修订(草稿)                          # ⑤ 必要时再走③或④
    return 交付(草稿)                    # ⑥ 返回 RunResult

没有例句、拒答、服务出错，分别返回什么？

缺例句：可以返回建议表达，并标明没有通过校验的播客例句。拒答：返回空表达列表和原因。空白输入：返回 invalid_input。数据库、模型或语料未就绪等故障：返回 error 和原因码。

固定流程和 Agent 在哪里分开？

① 到 ④ 两者共用。到了 ⑤，固定流程按规则补缺引文的位置；Agent 可以重新检查整份草稿，包括已经有引文的位置。最后两者都走 ⑥。
